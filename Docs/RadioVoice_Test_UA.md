# Перевірка мікрофона в packaged build

V або B перемикає єдиний стан передачі голосу: перше натискання вмикає мікрофон,
друге вимикає. Передавати може локальний гравець як на listen-server,
так і на клієнті. Dedicated server власного мікрофона не має.
Третє натискання знову вмикає, четверте знову вимикає. Відпускання клавіші
та її утримання не перемикають мікрофон: прив'язка використовує лише `IE_Pressed`.
Контролер відновлює стан перемикача після Blueprint-ініціалізації голосу
та при зміні персонажа; при втраті персонажа або виході передача зупиняється.
Оновлення A02 від 2026-09-27 прибрало окремий Blueprint B/FlipFlop шлях.
Receiver запускається незалежно від BeginPlay controller cast й зберігає готовність
до possession. Він повідомляє контролер про готовність. Ранній ON-запит чекає
receiver/session/device; UI показує застосований стан. [Зміни й сценарій V/B](A01_A02_Audio_Voice_UA.md).

## Перевірка Steam-сесії

1. Зробити новий package після компіляції змін C++; старий package не оновлюється
   від самого редагування коду або компіляції Editor target.
2. На двох ПК увійти в Steam під різними обліковими записами.
3. У Windows вибрати робочий мікрофон як стандартний пристрій запису та дозволити
   доступ до мікрофона для desktop applications.
4. Створити сесію через меню на першому ПК, приєднатися через меню на другому.
   Пряме відкриття gameplay-мапи без онлайн-сесії не перевіряє OSS voice:
   Unreal не обробляє голосові пакети, якщо немає жодної сесії.
5. На хості натиснути V, говорити: клієнт має чути голос. Натиснути V ще раз:
   клієнт більше не повинен чути мікрофон хоста.
6. Повторити в обидва боки для клієнта та при одночасно ввімкнених мікрофонах.
7. Повторити після виходу в меню та повторного входу в сесію.

## Діагностика в Development build

Консольна команда `HronoVoiceStatus` записує в лог:

- активну підсистему, кількість сесій та локальний номер гравця;
- requested, active та receiverReady (active — застосований OSS-запит; capture перевіряють через IsRecording);
- `IsRecording`, `Registered`, `Networked` і стан голосового движка;
- віддалених співрозмовників та їхній mute state.

`ToggleRadioTransmission` запускає той самий шлях, що й клавіша V.
У робочій Steam-сесії очікується `subsystem=STEAM`, `sessions` більше нуля,
після ввімкнення — `Registered: 1`, `Networked: 1`, `IsRecording: 1`.
Після вимкнення — `Networked: 0`; запис може завершуватися не миттєво,
оскільки Unreal дочитує останній буфер.

Якщо підсистема `NULL`, Steam не ініціалізувався або запуск зроблено з
`-nosteam`. Перевірити Steam та відповідність App ID збірки.
`Voice interface unavailable` або помилка реєстрації вказує на голосову
підсистему/пристрій запису; деталі є поруч у `LogOnlineVoice` та `LogVoiceCapture`.

Локальна перевірка NULL-підсистеми та успішна компіляція не замінюють
перевірку чутності між двома Steam-користувачами.

## Автоматична локальна перевірка

`Scripts/test_radio_voice.ps1` запускає два packaged Development-процеси
із NULL-підсистемою, IP-з'єднанням та реальним Windows-мікрофоном.
Потрібен staged Development package; стандартний каталог —
`Saved/RadioVoiceTestBuild/Windows`. Можна передати інший `-StageDirectory`.
Тест триває приблизно 35 секунд і перевіряє початковий вимкнений стан,
чотири послідовні перемикання (ON → OFF → ON → OFF), захоплення, отримання
голосу іншого процесу, відсутність mute та повне вимкнення запису/передачі.
Пороги відсікання тиші знижуються лише для цих тестових процесів,
щоб мережеві пакети можна було перевірити без розмови біля мікрофона.

Результат на 2026-09-18:

- Host: PASS; початковий OFF та цикл ON → OFF → ON → OFF; 517 голосових пакетів.
- Client: PASS; початковий OFF та цикл ON → OFF → ON → OFF; 508 голосових пакетів.
- В обох процесах під час передачі: `IsRecording: 1`, `Registered: 1`,
  `Networked: 1`, remote `Talking: 1`, `Muted: 0`.
- Після вимкнення в обох процесах: `IsRecording: 0`, `Networked: 0`.
- Початковий стан клієнта повторно синхронізується після запізнілого
  Blueprint `InitVoiceChat`; цей крок зберігає вже зроблені натискання V.
- Логи: `Saved/Logs/RadioVoiceNetHost.log`, `Saved/Logs/RadioVoiceNetClient.log`.
- Без сесії: `sessions=0`, `requested=0`, `IsRecording: 0`, `Networked: 0`;
  лог `Saved/Logs/RadioVoiceNoSession.log`.

Окремий Shipping package з цим виправленням:
`Saved/RadioVoiceFixedBuild/Windows/Hrono.exe`.

Для тестового package використано наявний cooked content. Нові зміни Blueprint
або мап потребують нового cook. Автоматичний тест перевіряє голосові дані та
мережевий шлях, але не суб'єктивну якість/гучність голосу на двох Steam-ПК.
