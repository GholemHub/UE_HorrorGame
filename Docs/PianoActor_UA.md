# Піаніно: взаємодія та перевірка

`/Game/_Alex/BP_Piano` — дочірній Blueprint `APianoActor`. Поставте його на карту з меню **Place Actors**. Він уже має модель `/Game/Fab/Piano/piano/StaticMeshes/piano`, бокс взаємодії, короткий демонстраційний акорд `S_PianoInteract` із класом `SC_HronoSFX` і `ATT_General`. Реальний запис можна підставити в полі **Piano Sound** без зміни C++. Карта `DemoMap1` автоматично не змінюється: розташування піаніно визначає автор рівня.

Гравець дивиться на піаніно з робочої відстані й натискає `E`. Клієнт посилає намір через чинний `Server_InteractWithEnvironment`, сервер перевіряє відстань і перешкоди та запускає один мережевий звук. `Interaction Cooldown Seconds` типово 0,25 с захищає від подвійного старту. `Piano Timeline=Both` дозволяє обом гравцям натискати й чути; Past/Future обмежує аудиторію. `bAutoSizeInteractionBox` підганяє колізію під модель; якщо потрібно зробити ціль тільки біля клавіш, вимкніть його в Blueprint і вручну задайте розмір та позицію `InteractionBox`.

Для ручної перевірки візьміть два окремі процеси — listen host і remote client — з однаковою збіркою. Кожен має один раз натиснути `E` і почути звук біля піаніно; інший гравець має почути ту саму подію рівно один раз із відповідною гучністю за відстанню. Натисніть далеко від нього або крізь стіну: новий звук не має запускатися. Швидко натисніть двічі й перевірте cooldown. Зайдіть другим клієнтом після попереднього натискання: звук не повинен програватися з історії. Повторіть для обох timeline, після смерті/повернення й travel; за потреби перевірте з 100–200 мс latency і 1–2% packet loss. Командлетний тест перевіряє серверну дію та колізійні канали, але не фактичну чутність у двох процесах.
